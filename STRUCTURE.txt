⚡ Quick Commands
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Local Development:

  Backend:
    cd backend
    pip install -r requirements.txt
    uvicorn app.main:app --reload

  Frontend:
    cd frontend
    npm install
    npm run dev

  Tests:
    cd backend
    pytest tests/

Deployment:

  Backend (Railway):
    railway login
    railway up

  Frontend (Netlify):
    netlify deploy --prod

  CI/CD:
    git push origin main
    (Auto-deploys via GitHub Actions)
