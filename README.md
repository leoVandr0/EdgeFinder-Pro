# EdgeFinder Pro

> Advanced forex and macroeconomic analytics platform - An open-source clone of A1Trading's EdgeFinder

[![Deploy Status](https://img.shields.io/badge/deploy-ready-brightgreen)](https://github.com)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

EdgeFinder Pro is a production-ready, cloud-deployable SaaS application that combines currency strength visualization, pair comparison dashboards, economic event calendars, AI-based news summarization, and trade signal generation.

## Features

- **Currency Strength Analysis** - Real-time weighted strength scores for major currencies (USD, EUR, GBP, JPY, CHF, AUD, CAD, NZD)
- **Pair Comparison** - Side-by-side analysis with divergence calculations and trading recommendations
- **Economic Calendar** - High-impact event tracking with forecast vs. actual data
- **AI-Powered Insights** - Automated trade signal generation with confidence scoring
- **News Sentiment Analysis** - Summarized forex news with sentiment scoring
- **Interactive Dashboards** - Beautiful visualizations using Recharts

## Tech Stack

### Frontend (Netlify)
- **Framework:** Vite + React 18
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Routing:** React Router v6
- **HTTP Client:** Axios

### Backend (Railway)
- **Framework:** FastAPI
- **Databases:**
  - PostgreSQL (Railway managed) - Analytics & indicators
  - MongoDB Atlas - News feeds & events
- **AI/NLP:** Built-in fallback sentiment analyzer + adapter for external APIs
- **Deployment:** Docker + Railway CLI

## Quick Start

### Prerequisites
- Node.js 18+
- Python 3.11+
- Git
- Netlify account
- Railway account

### Local Development

#### Backend Setup

```bash
cd backend

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Create .env file
cp .env.example .env
# Edit .env with your database URLs (optional for local dev)

# Run development server
python -m uvicorn app.main:app --reload

# API will be available at http://localhost:8000
# Docs at http://localhost:8000/docs
```

#### Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Create environment file
cp .env.production.example .env

# Set backend URL
echo "VITE_API_BASE_URL=http://localhost:8000" > .env

# Run development server
npm run dev

# App will be available at http://localhost:5173
```

## Deployment Guide

### Backend Deployment (Railway)

#### Option 1: Railway Dashboard (Recommended)

1. **Create Railway Account**
   - Go to [railway.app](https://railway.app)
   - Sign in with GitHub

2. **Create New Project**
   - Click "New Project" → "Deploy from GitHub"
   - Connect your forked repository
   - Select the `backend` directory as the root path

3. **Configure Environment Variables**
   - In Railway dashboard, go to Variables tab
   - Add the following:
     ```
     POSTGRES_URL=<auto-generated by Railway if you add PostgreSQL service>
     MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/edgefinder
     ALLOWED_ORIGINS=https://your-site.netlify.app
     ENVIRONMENT=production
     PORT=8000
     ```

4. **Add PostgreSQL Service (Optional)**
   - Click "New" → "Database" → "PostgreSQL"
   - Railway will auto-populate `POSTGRES_URL`

5. **Deploy**
   - Railway will automatically build using the Dockerfile
   - Your API will be live at: `https://your-app.railway.app`
   - Check logs in the Deployments tab

#### Option 2: Railway CLI

```bash
# Install Railway CLI
npm install -g @railway/cli

# Login
railway login

# Initialize project
cd backend
railway init

# Link to project
railway link

# Add environment variables
railway variables set MONGODB_URI="your_mongodb_uri"
railway variables set ALLOWED_ORIGINS="https://your-site.netlify.app"

# Deploy
railway up

# Get deployment URL
railway domain
```

### Frontend Deployment (Netlify)

#### Option 1: Netlify Dashboard (Recommended)

1. **Create Netlify Account**
   - Go to [app.netlify.com](https://app.netlify.com)
   - Sign in with GitHub

2. **Create New Site**
   - Click "Add new site" → "Import an existing project"
   - Choose your GitHub repository
   - Configure build settings:
     ```
     Base directory: frontend
     Build command: npm run build
     Publish directory: frontend/dist
     ```

3. **Configure Environment Variables**
   - Go to Site settings → Environment variables
   - Add:
     ```
     VITE_API_BASE_URL=https://your-backend.railway.app
     ```

4. **Deploy**
   - Click "Deploy site"
   - Your site will be live at: `https://your-site.netlify.app`
   - You can customize the domain in Domain settings

#### Option 2: Netlify CLI

```bash
# Install Netlify CLI
npm install -g netlify-cli

# Login
netlify login

# Navigate to frontend
cd frontend

# Build
npm run build

# Deploy
netlify deploy --prod --dir=dist

# Follow prompts to create new site or link existing
```

### MongoDB Atlas Setup (Optional)

If you want to use MongoDB for events storage:

1. Go to [mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas)
2. Create free cluster
3. Create database user
4. Whitelist IP: `0.0.0.0/0` (for Railway access)
5. Get connection string
6. Add to Railway environment: `MONGODB_URI=mongodb+srv://...`

## CI/CD Setup

The project includes GitHub Actions workflows for automated deployment.

### Required Secrets

Add these secrets in GitHub repository settings (Settings → Secrets and variables → Actions):

#### Backend Secrets
- `RAILWAY_TOKEN` - Get from Railway account settings
- `RAILWAY_API_URL` - Your Railway deployment URL (for notifications)

#### Frontend Secrets
- `NETLIFY_AUTH_TOKEN` - Get from Netlify User Settings → Applications
- `NETLIFY_SITE_ID` - Get from Site Settings → General → Site details
- `VITE_API_BASE_URL` - Your Railway backend URL

### Workflow Triggers

- **Backend:** Deploys automatically on push to `main` when `backend/**` files change
- **Frontend:** Deploys automatically on push to `main` when `frontend/**` files change
- **Tests:** Run automatically on PR and push to `main`/`develop`

## API Endpoints

### Currency Strength
- `GET /api/strength/` - Get all currency strengths
- `GET /api/strength/currency/{code}` - Get single currency strength

### Trading Insights
- `GET /api/insights/` - Get trade signals (limit param supported)
- `GET /api/insights/pair/{pair}` - Get insights for specific pair

### Economic Events
- `GET /api/events/` - Get economic calendar (filters: currency, impact, upcoming)
- `GET /api/events/today` - Today's events
- `GET /api/events/high-impact` - High-impact events only

### Pair Comparison
- `GET /api/pair-compare?base=EUR&quote=USD` - Compare two currencies
- `GET /api/pair-compare/{pair}` - Direct pair comparison (EUR/USD)

### News & Sentiment
- `GET /api/news-summary/` - Get summarized news with sentiment
- `GET /api/news-summary/sentiment` - Overall market sentiment
- `GET /api/news-summary/currency/{code}` - Currency-specific news

### Health & Docs
- `GET /` - API info and health check
- `GET /health` - Health check endpoint
- `GET /docs` - Interactive API documentation (Swagger UI)
- `GET /redoc` - Alternative API documentation (ReDoc)

## Troubleshooting

### Backend Issues

**Problem:** Database connection errors
```bash
# Check Railway logs
railway logs

# Verify environment variables
railway variables
```

**Problem:** CORS errors
- Ensure `ALLOWED_ORIGINS` includes your Netlify URL
- Check Railway logs for rejected requests

### Frontend Issues

**Problem:** API calls fail
- Verify `VITE_API_BASE_URL` in Netlify environment
- Check browser console for errors
- Verify backend is running: `curl https://your-backend.railway.app/health`

**Problem:** Build fails on Netlify
- Check Node version (should be 18+)
- Verify all dependencies in package.json
- Check Netlify build logs
